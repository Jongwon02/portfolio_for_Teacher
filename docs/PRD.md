# PRD — portfolio_for_Teacher

> 작성일: 2026-11-25 · 작성자: 신종원 · 상태: 초안 (지(智) 자료 추가 예정)

## 1. 개요

### 1.1 한 줄 정의
**"체·덕·지를 갖춘 사람이 아이들과 선생님을 위한 프로그램을 만든다"** 는 것을 실제 기록으로 증명하는 개인 포트폴리오 웹사이트.

### 1.2 배경
- 기존 포트폴리오(`For_My_Portfolio`)는 "아이디어를 현실로 만드는 크리에이터"라는 범용 정체성으로 작성되어 있다.
- 본 프로젝트는 이를 기반으로, **교육(에듀테크) 분야 프로그래머** 라는 구체적인 목표에 맞춰 메시지와 콘텐츠를 재구성한다.

### 1.3 핵심 철학 — 존 로크의 체·덕·지
존 로크는 『교육론(Some Thoughts Concerning Education)』에서 건강한 신체(체), 바른 덕성(덕), 지식(지)을 교육의 세 축으로 보았다.
나는 **좋은 교사란 체·덕·지를 갖추고, 이를 바탕으로 아이들에게 모범을 보이는 사람**이라고 생각한다.
아이들과 선생님을 위한 프로그램을 만드는 사람도 같은 기준을 갖춰야 한다는 것이 이 포트폴리오의 주장이며, 사이트의 각 축은 **주장이 아니라 증빙**으로 채운다.

## 4. 콘텐츠 요구사항 (체 → 덕 → 지)

### 4.1 체(體) — 꾸준한 신체 단련
**근거 자료:** 삼성헬스 내보내기 데이터 (`samsunghealth_sjw020722_20261125001315`, 원본은 저장소에 포함하지 않음)

데이터 분석 결과 (2023-08-28 ~ 2026-11-20 기준):

| 지표 | 값 |
| --- | --- |
| 총 운동 기록 | **889회** |
| 운동한 날 | **614일** (약 3년 3개월) |
| 최장 연속 운동 | **24일** |
| 실내 운동 (제자리 유산소) | 527회 · 약 379시간 · 약 229,700 kcal |
| 자전거 | 159회 · 455.9 km |
| 달리기 | 53회 · 159.3 km |
| 걷기 | 136회 · 158.5 km |
| 연도별 기록 | 2023: 76회 · 2024: 211회 · 2025: 181회 · 2026: 421회 |

**메시지:** "말이 아니라 3년간 889번의 기록으로 증명하는 꾸준함" — 2026년에는 운동 횟수가 전년의 2배 이상으로 증가.

**요구사항**
- R-체-1: 핵심 숫자(889회, 614일, 24일 연속 등)를 카드/카운터로 표시
- R-체-2: 월별 운동 횟수 추이 차트 (2023-08 ~ 2026-11) — 원본 CSV를 가공한 **집계 JSON만** 저장소에 포함
- R-체-3: 개인정보 보호 — 위치(GPS), 심박, 수면, 체중 등 원시 데이터는 공개하지 않음

### 4.2 덕(德) — 성실과 봉사
**근거 자료:** 표창장 이미지 (`KakaoTalk_20261125_003352948.jpg`)

| 항목 | 내용 |
| --- | --- |
| 상훈 | 표창장 제2491호 |
| 수여 | 충북지방병무청장 |
| 일자 | 2024년 12월 12일 |
| 복무 | 요양원 사회복무요원 (기관명 비공개) |
| 사유 | 평소 맡은 바 직무를 성실히 수행하여 **제11회 병무청 사회복무대상** 대상자로 선정 |
| 선발 규모 | 전국 사회복무요원 약 5만 명 중 **93명** 선발 |

**메시지:** 요양원에서 돌봄이 필요한 분들을 위해 성실하게 일했고, 그 결과 전국 약 5만 명 중 93명에게만 주어지는 사회복무대상에 선정됨. 돌봄과 배려는 아이들을 대하는 자세와 이어진다.

**요구사항**
- R-덕-1: 표창장 이미지와 핵심 내용을 함께 표시 (이미지 확대 보기)
- R-덕-1a: 표창장 이미지의 **근무 기관명은 가림 처리**한 뒤 게시 (원본 이미지는 저장소에 커밋 금지)
- R-덕-2: 요양원 근무 경험과 그 경험이 교육 분야 비전으로 이어지는 이야기 서술
- R-덕-3: "전국 사회복무요원 약 5만 명 중 93명 선발" 문구를 핵심 수치로 강조 (본인 검증 완료, 출처 링크가 있으면 함께 표기)

### 4.3 지(智) — 프로그래머로서의 역량 *(자료 추가 예정)*
| 프로젝트 | 보여줄 역량 | 상태 |
| --- | --- | --- |
| 보험 데이터 예측 | 데이터 분석·머신러닝 모델링 | 자료 대기 |
| 해커톤 본선 진출작 | 짧은 기간 내 기획·구현·협업 | 자료 대기 |
| 소상공인·중소경영인 MBTI 진단서 (`MBTI_For_Enterprise`) | 사용자 중심 진단 도구 설계, 실서비스 구현 | 자료 대기 |

**요구사항**
- R-지-1: 프로젝트마다 문제 → 해결 방법 → 결과(성과) → 기술 스택 → 링크(GitHub/데모)를 표시
- R-지-2: 각 프로젝트가 "교육용 프로그램 개발"에 어떻게 이어지는지 한 줄 연결 문구 작성
- R-지-3: 해커톤 본선 진출은 증빙(공지·인증서 등)을 함께 표시

### 4.4 비전 — 왜 교육인가
- R-비전-1: "아이들을 위한, 그리고 선생님을 위한 프로그램을 만드는 프로그래머"라는 목표를 히어로 문구로 명시
- R-비전-2: 체·덕·지 → 좋은 교사의 조건 → 그 조건을 갖춘 개발자라는 논리 흐름을 사이트 전체에 반영

## 5. 정보 구조 (페이지 구성안)

단일 페이지 스크롤 구조를 유지한다 (기존 Next.js 구조 재사용).

1. **Hero** — 목표 선언 + 체·덕·지 키워드
2. **Philosophy** — 존 로크의 체·덕·지와 "좋은 교사란" 정의
3. **體 체** — 운동 기록 숫자 카드 + 월별 추이 차트
4. **德 덕** — 표창장 + 사회복무 이야기
5. **智 지** — 프로젝트 3개 (보험 예측, 해커톤, MBTI 진단서)
6. **Vision** — 만들고 싶은 교육 프로그램
7. **Contact**
